# 📊 Online Retail — Data Analysis

Projeto de **análise de dados de vendas** desenvolvido utilizando **Power BI**.

O objetivo é transformar os dados tratados na etapa de Data Cleaning em informações e indicadores que auxiliem na compreensão do comportamento das vendas.

## 🎯 Objetivo

Realizar uma análise exploratória da base de vendas, identificando:

* Faturamento e desempenho das vendas
* Produtos mais vendidos
* Comportamento dos clientes
* Desempenho por país
* Evolução das vendas ao longo do tempo

## 🛠️ Tecnologias

* 📊 Power BI
* 🐍 Python
* 🐼 Pandas
* 📄 CSV

## 📌 Etapas

1. Importação da base de dados tratada.
2. Modelagem e preparação dos dados no Power BI.
3. Criação de métricas e indicadores.
4. Desenvolvimento de visualizações.
5. Análise dos principais resultados.

## 📈 Dashboard

O dashboard será desenvolvido no **Power BI**, apresentando os principais indicadores e insights encontrados durante a análise.
